# Credex AI Spend Audit

The Credex AI Spend Audit is a tool designed to help businesses analyze their spending on various AI tools (like Cursor, GitHub Copilot, Claude, ChatGPT, etc.) and identify potential savings by optimizing plans or consolidating tools. 

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
